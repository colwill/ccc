Narration

Read the story aloud in a natural voice

ccc can narrate each step with Kokoro, an open voice model that runs on this computer, so nothing is sent to a speech service. Where this device cannot run it, the browser's voice reads instead.

  • Downloads once350 MB, the first time you turn narration on.
  • One copyKept in ccc's cache and used by every ccc window and VS Code instance. It runs on your graphics card.
  • KeptLines it has read are saved beside it, so a replay you have heard starts narrated at once.
  • Goes with your PRLines you voice are pushed with the branch's replay, so reviewers just press play. Turn it off for a branch, or everywhere with git config ccc.replay.voice false.
  • Removableccc voice remove deletes it. Apache 2.0 licence.
